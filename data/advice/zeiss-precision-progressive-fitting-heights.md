# ZEISS Precision Progressive range — minimum fitting heights

## Product-line fitting heights

> "Fitting heights
> For more reading comfort we recommend adding 2 mm to the minimum fitting
> height, especially for higher plus powers (>0.75D)."
> — *ZEISS Precision Progressive Range Portfolio Brochure*

For the Precision Pure / Precision Plus / Precision Superb / Individual 2
product line, corridor length and minimum fitting height are given
together:

| Product | Corridor length | Minimum fitting height |
|---|---|---|
| Precision Pure | 3 fixed lengths: 10mm / 12mm / 14mm | 14mm / 16mm / 18mm |
| Precision Plus | Specified FrameFit® value (−1 to 6) or variable | 14mm and greater |
| Precision Superb | Specified FrameFit® value (−1 to 6) or variable | 14mm and greater |
| Individual 2 | Specified FrameFit® value (−1 to 6) or variable | 14mm and greater |

## Application to this project

Zeiss's figures corroborate the same 14–20mm range for **fitting height**
found in Rodenstock's documentation
(`rodenstock-frame-fitting-heights.md`) and HOYA's
(`hoya-2026-progressive-fitting-heights.md`) — this is a fitting-height
number, not a frame/B-height number, and should not be compared directly
against this project's `PROGRESSIVE_MIN_B_HEIGHT_MM` (a B-height
constraint). The brochure does not give a frame-depth/B-height figure
directly; it's included in this corpus for the fitting-height
cross-reference, not as a source for the B-height threshold itself.
